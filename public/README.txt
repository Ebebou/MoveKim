LFFavicon package
=================

1. Copy every file from this archive to the root of your website
   (or to the folder matching the configured path: /).
2. Paste the following lines inside the <head> of your pages:

<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicon-96x96.png" type="image/png" sizes="96x96">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#c00e11">

Generated for free with LFFavicon, https://lffavicon.com
